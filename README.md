# arduino-distance-reader-LCD-screen
Ultrasonic Sensor reads distance in centimeters and prints the distance to an LCD Screen

-Components-
Arduino Mega 2560 Microcontroller
Breadboard
Jumper Wires
LCD1602 Module
Ultrasonic Sensor Module
10k Potentionmeter
220ohm Resistor

-Libraries-
LiquidCrystal by Arduino, Adafruit

-IMPORTANT-
The circuit diagram shows pin 11 connected to Register Select and pin 12 connected to Enable, but if you have a different arduino board, connect it according to your SPI Bus pins
Pin 11 = MOSI/PICO
Pin 12 = MISO/POCI
